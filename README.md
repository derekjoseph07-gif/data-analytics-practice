# Data Analytics Practice

A collection of guided and self-directed exercises completed while building
foundations in Python, SQL, pandas, and statistics as part of my transition
into data analytics. See my [main portfolio project](https://github.com/derekjoseph07-gif/sales-promo-analysis)
for an original, independent analysis.

| Project | Skills |
|---|---|
| [Titanic Survival Analysis](Titanic_Survival_Analysis.ipynb) | missing-data imputation, hypothesis testing, logistic regression |
| [Analyzing Online Sports Revenue](Analyzing_Online_Sports_Revenue.ipynb) | merging, qcut, cut, custom binning |
| [Analyzing Crime in Los Angeles](Analyzing_Crime_in_Los_Angeles.ipynb) | pd.cut, np.select, time-based features |

| [Will This Customer Purchase Your Product](Will_This_Customer_Purchase_Your_Product.ipynb) | correlation, binomial probability |
